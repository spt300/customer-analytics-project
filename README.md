# customer-analytics-project
## Project Overview

This project analyzes customer behavior using SQL, SQLite, Pandas, and Jupyter Notebook.

## Objectives

* Calculate Customer Lifetime Value (CLV)
* Identify repeat customers
* Analyze revenue by city
* Segment customers by value
* Calculate revenue contribution

## Tools Used

* Python
* SQLite
* Pandas
* Jupyter Notebook

## Key Findings

* Top Customer: Rahul
* Lifetime Value: ₹17,000
* Revenue Contribution: 36.97%
* Top City: Delhi
* Repeat Customers: 3

* SQL Aggregation
* CASE WHEN
* CTEs
* Customer Segmentation
* Business Analysis
